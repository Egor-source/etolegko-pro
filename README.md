# Измерение скорости скачивания

Консольная утилита для измерения скорости скачивания одного ресурса по HTTP или HTTPS. Утилита выполняет 10 последовательных GET-запросов, полностью считывает каждый ответ и выводит результаты отдельных запросов и общую статистику.

## Требования и установка

Рекомендуется Node.js 26 LTS. Также поддерживается Node.js 24 LTS. Для установки зависимостей нужен npm. Если вы используете `nvm`, команда `nvm install` выберет версию из `.nvmrc`.

Установите зависимости из корня проекта.

```bash
npm ci
```

## Запуск

```bash
npm start -- 'https://example.com/'
npm start -- --help
```

Передайте один абсолютный URL. URL с параметрами запроса заключайте в кавычки, чтобы оболочка передала его одним аргументом.

Скомпилируйте проект, чтобы запустить собранную версию.

```bash
npm run build
npm run start:prod -- 'https://example.com/'
```

При первой сетевой ошибке, обрыве потока, статусе вне диапазона `200–299` или превышении 30 секунд на один запрос утилита завершает замер с кодом `1` и сообщает номер запроса. Таймаут охватывает получение заголовков и чтение тела. Перенаправление считается ошибкой HTTP. Статистика выводится после десяти успешных запросов.

## Расчёт метрик

- Время запроса измеряется через `performance.now()` от начала GET-запроса до конца чтения тела. Вывод в консоль выполняется после замера.
- Суммарное время равно сумме продолжительностей десяти запросов. Среднее время равно этой сумме, делённой на десять.
- Общий объём равен сумме размеров фактически прочитанных частей тела ответа. Тело обрабатывается потоком, в памяти хранятся только данные, необходимые для текущего чтения, и метрики.
- Средняя скорость равна общему объёму в мегабайтах, делённому на суммарное время в секундах. При нулевом объёме или времени скорость равна нулю.
- Время в отчёте указано в миллисекундах, объём в десятичных мегабайтах (`1 MB = 1 000 000` байт), скорость в `MB/s`. Значения округляются до двух знаков только при выводе.

### Ограничения измерений

- Время включает ожидание ответа сервера и, при открытии соединения, установление соединения. Node.js может переиспользовать соединения между запросами.
- При HTTP-сжатии нативный `fetch` отдаёт распакованные данные. Объём и скорость отражают размер тела после распаковки.
- Результат относится к выбранному ресурсу. На него влияют размер ответа, нагрузка на сервер, сетевые условия и кэши на пути запроса.

## Архитектура

- `src/index.ts` запускает CLI и устанавливает код завершения процесса.
- `src/cli/benchmark.cli.ts` использует Commander.js для разбора аргументов и генерации справки, проверяет URL и выводит результат или ошибку.
- `src/services/benchmark.service.ts` выполняет запросы нативным `fetch`, считывает поток и рассчитывает метрики. В тестах можно подставить HTTP-клиент и функцию измерения времени.
- `src/types/` содержит типы метрик, `src/utils/` — функции форматирования, `tests/` — модульные тесты на Vitest.
